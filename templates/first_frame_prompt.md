# 首帧提示词模板

## 用途

- 镜号：
- 场景：
- 年代：
- 画幅：16:9，2048×1152
- 参考图：
- 命名：`首帧/<id>_first.png`

## 提示词

```text
16:9 横构图，2048×1152。
<年代/地点/光线>。
<人物：年龄、服装、发型、眼镜、姿态、视线>。
<动作：第一帧停在哪>。
<镜头：景别、焦段、机位>。
<质感：胶片颗粒、低饱和、写实>。
画面无文字、无水印、无边框、不要多格拼图。
```

## 负面

```text
不要正脸（如适用）、不要现代建筑、不要液晶屏、不要运动鞋、
不要多手、不要文字、不要水印、不要拼图。
```
