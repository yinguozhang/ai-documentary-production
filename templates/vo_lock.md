## 5. 修改规则

1. 锁定后不直接改 `vo.csv`；
2. 新建 `vo_v2.csv`，先跑 `vo_diff.py`；
3. 只改受影响的文件；
4. 旧版本留在 `vo_versions/`；
5. 改完重新锁版本。

```bash
python scripts/vo_diff.py --old vo_versions/vo_v1.csv --new vo.csv --out vo_diff.md
```
