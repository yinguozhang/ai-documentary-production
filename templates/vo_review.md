## 4. 读出来

- [ ] 每句能一口气读完
- [ ] 没有拗口的词组合
- [ ] 没有连续三个“的”
- [ ] 没有“被/进行/实现/彰显/体现”
- [ ] 句间留 0.3–1.0 秒气口
- [ ] 一段旁白可跨多镜；普通镜头最多一段；长镜头可多段但全在镜内
- [ ] 普通/跨镜头气口窗口包含切点；长镜头内部不需要
- [ ] 无旁白短镜头只在需要时使用（可选）

## 5. 意象/口号

- [ ] 每个意象有具体物/动作锚点（如九连环→环扣）
- [ ] 一条意象链，没有混合比喻（火种/种子/明珠/山峰乱飞）
- [ ] 抽象词放在具体物之后
- [ ] “大门/种子/火种/明珠”如果是 motif，已确认能落地
- [ ] 没有“不是…而是…/既…又…”连发
- [ ] 没有“三尺讲台/教书育人/心有大我/至诚报国”
- [ ] 结尾落在具体物/动作，不落口号
