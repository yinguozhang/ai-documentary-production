# 视频生成与评审

## 默认

- 先锁 `vo.csv` 和 animatic，再生成视频；
- MiniMax H3，768P；
- 一版制；不能用才补一版；
- 首帧图生视频；
- 生成时长 = 成片 + 1 秒，最短 4 秒；
- 失败任务不计费，但要有 fallback。

## 提示词后缀

```text
保持首帧图中人物、服装、场景与光线不变。
<动作>；<表情>。
<镜头>。
最后停在结束姿态，保持不动。
只保留环境音效或人声，不要配乐、不要 BGM、不要旋律。
画面无文字。
```

## 任务日志

`tasks.json` 记录：

```text
id,provider,model,duration,status,task_id,file,cost_cny,error
```

## 评审

- 每条视频抽 5–8 帧做接触表；
- 看动作是否真的发生；
- 看首尾能否接下一镜；
- 看人物/手/道具/背景；
- 结论只用：用 / 有条件用 / 重生成。

## 常见失败

- 动作没发生：重生成，不硬剪；
- 人物变脸：换参考图/侧影；
- 多手/穿模：重生成；
- 背景穿帮：裁切/换镜；
- 生成带音乐：丢弃音轨或重生成。

## 门禁

- G5：每镜有结论；成本已记录；不能用的一版已标重生成。
