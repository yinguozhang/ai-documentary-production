# 旁白锁定与变更控制

## 为什么需要

改一句旁白，不应该重写全项目。  
出现“全改”，通常是因为：

1. 旁白文字被复制到多个文件；
2. 没有锁定版本；
3. agent 没有依赖图，只能全量重出。

解决办法不是“更小心”，是**锁定 + 派生 + diff**。

---

## 三个层次

```text
第一层：vo.csv          旁白唯一真相源
第二层：timeline/srt    由脚本派生
第三层：shots/prompts   创作层，只在语义变了时改
```

- `vo.csv` 改，派生层用脚本重跑；
- `shots.csv` 只写 `vo_ids`，不复制旁白；
- 提示词只写画面，不复述旁白；
- 素材层能复用就复用。

---

## G2.5：旁白锁定

G2 不是“写完 vo.csv”，而是：

```text
vo.csv
vo_v1_scratch.wav    # 试读/TTS 样音，量真实时长
vo_lock.md           # 版本、每句时长、语速、发音、语气
vo_versions/vo_v1.csv
```

### 为什么要 scratch 音频

按字数估的时长不等于读出来的时长。  
5 秒的句子可能读成 5.8 秒；不先试读，镜头时长全白排。

### 锁定检查

- 事实核对；
- 读一遍不拗口；
- 句间气口；
- 时间码和 scratch 一致；
- `shots.csv` 的 `vo_ids` 已对应；
- 版本号/日期。

---

## 版本规则

```text
vo_versions/
  vo_v1.csv
  vo_v2.csv
vo.csv              # 当前使用版本
vo_v1_scratch.wav
vo_lock.md
```

- 锁定后不直接改旧版；
- 新建 `vo_v2.csv`；
- 跑 `vo_diff.py`；
- 只改受影响文件；
- 更新 `vo_lock.md`。

---

## 变更影响矩阵

| 变化 | 必改 | 通常不改 |
|---|---|---|
| 只换词，意思/时长不变 | `vo.csv`、`subtitles.srt` | `shots.csv`、提示词、首帧 |
| 句长/停顿变化 | `vo.csv`、`timeline.csv`、镜头时长 | 提示词大部分 |
| 镜头分配变化 | `vo.csv`、`shots.csv`、部分提示词 | 已生成且能复用的素材 |
| 叙事顺序/事实变化 | 旁白、镜头顺序、部分提示词 | 可复用素材 |
| 只换配音/音色 | 音频、`timeline.csv` | 旁白文字、镜头内容 |

---

## `vo_diff.py`

```bash
python scripts/vo_diff.py \
  --old vo_versions/vo_v1.csv \
  --new vo.csv \
  --out vo_diff.md
```

输出：

- 新增/删除/改词/改时间的 cue；
- 总时长差；
- 受影响镜号；
- 建议重跑的文件；
- 不应该动的文件。

### 判定规则

- 文本变了 → 字幕必须重跑；
- 时间变了 → timeline/镜头时长要检查；
- `shot_ids` 变了 → 分镜/提示词要检查；
- 只改标点/空格 → 视为不变；
- 只改语气词 → 字幕重跑，画面不动。

---

## Agent 规则

把下面写进项目规则或对话开头：

> 旁白已锁定。任何旁白修改，先跑 `vo_diff.py`，列出受影响文件；  
> 禁止因为改一句旁白而重写全项目；  
> 下游只引用 `vo_id`，不复制旁白全文。

---

## 省 token 的正确姿势

- 机械传播：脚本；
- 创作返工：只改语义真的变了的镜头/提示词；
- 不把旁白复制进 `shots.csv`/提示词/评审表；
- 不每次让 agent “读全部文件再重写”；
- 用 `vo_diff.md` 作为变更单。

---

## 常见错误

- 直接改 `vo.csv` 不留版本；
- 改完旁白不重跑字幕；
- 改一句旁白就重写所有提示词；
- 用字数估算时长，不试读；
- `shots.csv` 里复制旁白全文；
- 提示词里写“旁白说……”。
