# 旁白写作：两种写法，两套标准

## 先纠正一个错误

这两句是诗性解说的好例子，不是反例：

> 在江南苏州，一个少年，被九连环的环扣谜题，叩开了数学世界的大门。  
> 环环相扣的逻辑，埋下了他一生求索的种子。

它们是**诗性解说**的好例子。  
不能拿“每句必须有硬信息”的解释型标准去压它们。

---

## 两种旁白

| 类型 | 做什么 | 事实由谁给 | 风险 |
|---|---|---|---|
| **诗性/意象型** | 用具体物、动作、比喻，建立情绪和主题 | 画面、字幕、上下文、少量事实句 | 意象悬空、混合比喻、全程抒情 |
| **解释型** | 交代年份、人名、数字、因果、关系 | 旁白为主 | 像说明书、信息堆叠、没有呼吸 |
| **混合型**（最常用） | 诗性开场，解释型中段，诗性收尾 | 分工 | 两种语气打架 |

一个片子里可以两种都有。  
**开头可以诗，讲“1+5”时必须解释。**

---

## 从这两句学什么

### 1. 具体锚点

“江南苏州”“少年”“九连环”——三个具体物，先把画面钉住。  
没有这三个锚点，“叩开数学大门”就是空话；有了它们，比喻才落地。

### 2. 一条意象链

```text
九连环 → 环扣 → 环环相扣的逻辑 → 一生求索的种子
```

从“物”到“理”再到“人”，一条链走到底。  
不是“大门 + 种子 + 火种 + 明珠”四个比喻乱飞。

### 3. 动词把抽象动作变成身体动作

- “叩开”比“走进/了解/接触”有力；
- “埋下”比“开始/产生”有画面；
- “环扣”既是九连环的零件，也是逻辑的关系。

### 4. 声音有节奏

```text
在江南苏州（6）／一个少年（4）
被九连环的环扣谜题（9）／叩开了数学世界的大门（9）
```

短—短—长—长；读出来有呼吸，不是论文句。

### 5. 留白

它没有解释九连环怎么解，也没有解释数学大门是什么。  
画面、音乐、下一句会接住。  
**诗性旁白不负责把话说完。**

### 6. 主题句放在转折处

“一生求索”是主题，但只出现一次，放在第二句结尾。  
如果每句都“一生/命运/时代”，就变成朗诵。

---

## 诗性旁白的规则

1. **每个意象有物/动作锚点**：能指向画面里的一个东西。
2. **一条意象链到底**：九连环→环扣→逻辑→种子；不要中途换火种/明珠/山峰。
3. **抽象词放在具体物之后**：先“九连环”，再“逻辑”，再“一生”。
4. **一句一个画面/动作**，不要在一句里塞三个事实。
5. **长短句交替**，读出来有节奏；不要连续四字口号。
6. **留白**：画面能演的，不解释；音乐能托的，不点破。
7. **主题句只放转折/结尾**，不要每句升华。
8. **关键事实单独给一句**：诗性不能替代“1962 年、1+5、1+4”这种信息。

---

## 解释型旁白的规则

用在必须讲清的地方：

- 年份、人名、关系、数字、因果；
- 一句一个信息；
- 主动句、短句；
- 数字翻译成人的尺度；
- 第一次出现的人名给身份；
- 不复述画面；
- 不堆形容词。

例：

> 1962 年，他证到 1+5；第二年，推到 1+4。  
> 这是当时世界上最好的结果。

这不是“比诗性高级”，只是**分工不同**。

---

## 30 秒怎么混

```text
0–3s    诗性钩子：一个物件/动作
3–12s   解释型：他是谁、做了什么、为什么难
12–22s  诗性/解释混合：转折、代价
22–30s  诗性回声：回到开场物件
```

旁白量 20–24 秒，留 6–10 秒气口。  
诗性句不要超过一半；关键事实必须有一句解释型。

## 检查器怎么用

`narration_lint.py` 只能查“形式”，不能判断“意象好不好”。

```bash
# 诗性/意象型：不把 大门/种子/明珠 当自动错误
python scripts/narration_lint.py --text vo.csv --style lyrical

# 解释型：更严格，提示这些词是否真的有锚点
python scripts/narration_lint.py --text vo.csv --style explanatory
```

它查：

- 长句、逗号过多；
- 名词化、被动；
- 重复句首；
- 无锚点口号；
- 解释型里的空泛比喻。

它不查：

- 意象是否美；
- 比喻是否新鲜；
- 情绪是否准确；
- 这句话是否该存在。

**最终判断还是读出来。**

## 定稿检查

### 诗性段

- [ ] 每个意象有具体物/动作；
- [ ] 一条意象链，没有混合比喻；
- [ ] 抽象词在具体物之后；
- [ ] 长短句有节奏；
- [ ] 主题句没有连发；
- [ ] 关键事实另有一句解释。

### 解释段

- [ ] 每句一个信息；
- [ ] 年份/人名/数字/因果清楚；
- [ ] 人名第一次出现有身份；
- [ ] 没有说明书腔；
- [ ] 没有为了对画面而改字。

### 全片

- [ ] 读一遍，不拗口；
- [ ] 句间有气口；
- [ ] 旁白没有铺满；
- [ ] 结尾落在具体物/动作，不落口号。

## 叙事型旁白：清楚，但不直白

这是本 skill 的默认偏好，尤其适合人物/历史短片。

### 先讲清楚

- 观众要能复述：**谁、在哪、发生了什么、为什么重要**；
- 事件之间要有因果，不是资料条目；
- 关键转折要有一句“落点”，不能全靠画面猜。

### 不要太直白

不写：

- “他很努力”“他热爱数学”“他一生奉献”；
- “这体现了……精神”“他是一位伟大的……”；
- 资料摘要式的“某年、某年、某年”。

改写：

- 用具体动作代替评价：**把算式写在账本背面**；
- 用物件代替情绪：**信封上只有两个字：《科学》**；
- 用短句做转折：**五次方程，解法错了。**

### 再诗意一点

- 先物后人，先动作后主题；
- 一条意象链，不要四个比喻乱飞；
- 长短句交替，读出来有呼吸；
- 结尾落在具体物/动作/名字，不落口号。

### 可以多加几句，但……

允许比“最小信息量”多 1–2 句，条件是每句至少提供：

- 一个新事实；
- 一个新画面/动作；
- 一个新因果；
- 或一个必要的呼吸/转折。

不允许：

- 用形容词凑时长；
- 把同一意思换三种说法；
- 每句都升华。

### 三问自检

1. 删掉所有形容词，故事还成立吗？
2. 每句是不是在推进，而不是在总结？
3. 最后一句，是落在具体物/动作/名字，还是落在口号？
