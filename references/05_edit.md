# 粗剪、字幕、CapCut

## 工程

- 代理剪辑 1280×720 / 25fps；
- 所有生成素材静音；
- 按 `timeline.csv` 入出点；
- 先拼段落，再拼全片。

## 字幕

- 16–20 字/行，最多 2 行；
- 字号 44–46px（1080p）；
- 文本框 1520–1600px；
- 左右 ≥100px，底部 ≥70px；
- 长句在标点断行；
- 不要用字幕补事实。

## 声音

- 旁白从 `vo.csv` 生成，不跟镜头绑定；
- 一句旁白跨 2–3 镜时，画面切、旁白不断；
- 不同旁白之间留 0.3–1.0 秒气口，不要铺满；
- 旁白单独一轨；
- 音乐单独一轨；
- 音效单独一轨；
- J/L cut：旁白可比画面早 0.3–0.8 秒、晚出 0.3–0.8 秒。

## 交接

导出：

```text
final.mp4（无音乐）
vo.wav
music/A-E.wav
cue_sheet.csv
subtitles.srt
```

## 门禁

- G6：无黑帧/跳帧；字幕不溢出；总长对。
