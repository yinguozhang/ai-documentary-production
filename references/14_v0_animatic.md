# v0：animatic（静帧/黑帧 + 旁白）

## 定义

本项目里 **v0 = animatic**，不是纯旁白音频。

```text
v0    animatic：静帧/黑帧 + 旁白 + 时间线
v1    粗剪：视频 + 旁白 + 字幕
final 终版
```

不另外生成“只有旁白的 v0”。

## 什么时候出

```text
旁白文案 → 用户确认
  → 2–3 个音色试听 → 用户选定
  → 整条 scratch
  → 排 shots.csv / timeline.csv
  → 生成 animatic（v0）
  → 提醒用户听气口/看节奏
  → 用户确认
  → 才出首帧、生成视频
```

v0 是第一个“能看”的版本，但画面还是静帧/黑帧，用来判断：

- 句子之间的气口；
- 镜头时长和切点；
- 哪些气口需要无旁白短镜头；
- 整体节奏是否赶/拖；
- 总时长。

## 必须提醒用户

v0 生成后，单独说：

> v0 animatic 已生成：`animatic.mp4` + `timeline.csv`。  
> 请先听一遍，检查句子之间的气口是否合适：有没有赶、有没有拖。  
> 确认后我再出首帧、生成视频；先不动画面。

不要先把首帧/视频做完再让用户看 v0。

## 检查什么

### 气口

- 句间是否听得出来在换气；
- 有没有两句黏在一起；
- 有没有停太久、像断片；
- 段落转换是否比句间更长；
- 有区间时是否取了较大的值。

### 节奏

- 普通镜头是不是只承载一段旁白；长镜头多段是否都完整在镜内；
- 普通/跨镜头气口窗口里是否有切点；长镜头内部不需要；
- 有没有镜头太长/太短；
- 无旁白气口镜头是否够用；
- 总时长是否在目标附近。

### 声音/文本

- 人名、术语、数字读法；
- 重音是否落在关键事实；
- 有没有拗口句；
- 字幕是否会在一个镜头里换两次。

## 工具

```bash
# 先出时间线
python scripts/timeline.py --shots shots.csv --vo vo.csv --out timeline.csv --animatic animatic.mp4

# 只看时间码的气口（不生成视频）
python scripts/vo_gap_report.py --vo vo.csv --audio vo_scratch.wav --out vo_gap.md
```

`vo_gap_report.py` 只是内部检查，不是另一个版本。
